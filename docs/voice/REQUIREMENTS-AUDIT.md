## 結論

MVPの安全境界と通常診断へのフォールバックは、実装と自動検証で概ね成立している。Geminiの実APIは合成音声で、候補生成・資料表示・手動修正・設問移動まで確認済みである。

ただし、音声体験そのものの受け入れ完了とはまだ判定しない。実マイク／iPhone Safari／OpenAI 2.1・Miniの実接続、自然な日本語と不要な確認の遵守、割り込み・権限拒否・通信断の人間評価、Gemini音声セッションでの3問目確定から結果遷移が未検証である。検証用Edgeタブのテスト音声入力解除も確認できていないため、通常利用前の再読み込みが必要である。

## ブラウザ検証の扱い

確認済みなのは、390px相当のEdge経路での合成音声によるGemini接続・候補表示・資料表示・手動修正・設問移動、および別の手動経路での3問確定から既存結果までである（QA 62–66行）。同一の実音声セッションで3問目を確定し、結果画面へ遷移する直前に画面保存操作がタイムアウトしたため、その連続経路は確認済みと数えない（QA 71行、PROGRESS 11行）。

また、検証専用Edgeタブにテスト音声入力を差し替えた状態の解除は確認できていない。通常の実マイク利用前にタブを再読み込みする必要がある。これは成果物の機能判定ではなく、検証環境の安全な後始末に関する注意である。

## 過剰な成功主張を避けるための修正点

- QAの「2.1 → Mini → Gemini → 2.1」は、現状ではUI上の選択切替の証拠であり、モデルの比較検証結果ではない。実接続・同条件評価と分けて表示する。
- 「Gemini実APIで3問確認済み」は、合成音声による候補生成と、手動経路の確定／結果遷移が混在しやすい。同一音声セッションで最後まで確認したとは記載しない。
- 「自然な日本語」「確認質問をしない」はPromptと少数例の再テストであり、全体の遵守保証ではない。特に不要な先走り発話の残存を明記したままにする。
- 「会話全文を保存しない」は運営アプリ側の保存・評価出力についての主張に限定する。Gemini無料枠などProvider側の保持・改善利用を含まない。
- 最新の自動検証は122件であり、旧い105件／120件を別資料に再掲しない。現行QA.md 46行は更新済み。

## 残課題（優先順）

### P0: 受け入れ前に必要

1. 新しい検証タブでテスト音声入力が解除されていることを確認し、Geminiの実接続を3問目の確定・結果遷移まで一続きで再確認する。
2. 実マイクで、許可・拒否・未接続、通信断、再接続、AI発話中の割り込み、画面離脱時の停止を人間が確認する。
3. iPhone Safari（HTTPS）で、マイク、音声再生、イヤホン/Bluetooth、画面離脱、狭幅レイアウトを確認する。
4. OpenAI 2.1とMiniを同じ設問・発話セットで接続し、少なくとも理解、不要な確認、自然さ、応答遅延、完了、費用を比較する。キーや課金条件が用意できない間は「切替可能だが実Provider未検証」と明記する。
5. 日本語の自然さと会話遵守の評価表を定義する。各モデル・各設問で複数試行し、発話の正解ラベルを本人または評価者が付け、修正率と理解正解率を分離する。合格閾値と必要サンプル数を先に決める。

### P1: 公開前に必要

1. モデルがツールを使わず確認質問や次問移動を発話した場合の検出・抑制策を検討する。Promptだけを仕様上の保証にしない。
2. `show_sources`を呼ばずに説明したケースを検出できるログ／評価項目を追加し、資料表示と説明内容の対応を確認する。
3. 利用者単位の認証、分散レート制限、プロバイダー側の予算上限、Provider保持条件の確認を追加する。現行の1プロセス毎時20接続と10分停止は課金上限ではない。
4. 実離脱率、音声開始成功率、結果到達率、権限拒否率、通信断率、p50/p95応答時間、Provider別費用、確認質問率、skip率、手動修正率、理解正解率を、同意・最小限のデータで集計できる設計にする。
5. 出典の専門家レビューと対象地域の一次資料追加を行う。現行の資料は国の制度・維持管理資料であり、県の予算案や特定地域の効果を直接裏付けない。

## 監査判定

コード品質・自動検証・プライバシー境界のMVP基礎は受け入れ可能な水準に近い。しかし、音声UXとProvider横断互換性を含む「音声MVP全体」は、上記P0が残っているため未完了と判定する。現時点の安全な表現は「Gemini合成音声を中心とした限定的な実証と、手動フォールバックおよび自動境界検証が完了」であり、「自然な音声インタビューが検証済み」「2.1/Miniを比較済み」「3問を同一音声経路で結果まで完了済み」とは言えない。
